# Unity Graphics Programming - English Translation

This repository contains AI-assisted English translations of the Japanese **Unity Graphics Programming** book series (Volumes 1-4), along with the accompanying Unity sample projects.

## Status

**Work in Progress**

- Translations: Complete (38 chapters across 4 volumes)
- Unity Projects: Upgrading to Unity 6.3 LTS (untested in many cases)
- PDFs: Generated for all 4 volumes

## Contents

### Translations

English markdown translations are in the `/Translations` folder:

| Volume | Chapters | Topics |
|--------|----------|--------|
| Volume 1 | 10 | Compute Shaders, Boids, Fluid Simulation (Grid & SPH), Geometry Shaders, Marching Cubes, MCMC Sampling, Procedural Modeling |
| Volume 2 | 10 | GPU Voxelizer, GPU Trails, Geometry Shader Lines, Projection Spray, Procedural Noise, Curl Noise, Shape Matching, Space Filling, Image Effects, SSR |
| Volume 3 | 8 | Reaction Diffusion, Strange Attractors, Geodesic Dome, Matrix LED, GPU Raymarching, Grass & Fur Shells, Crystal Caustics, Soft Deformation |
| Volume 4 | 7 | Space Colonization, Automatic Differentiation, Kajiya-Kay Hair, Temporal Reprojection, GPU Cloth, Screen-Space Fluid, Cosine Gradient |
